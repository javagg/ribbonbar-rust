# Office Fluent UI（Qitan Ribbon Office）Ribbon 风格研究笔记

> 来源：Qitan Ribbon Office 商业控件截图（蓝色 / 绿色两套主题）。
> 用途：作为本 demo gpui 版 RibbonBar 改造的设计规范。日期：2026-09-29。

---

## 1. 整体结构（自上而下）

```
┌────────────────────────────────────────────────────────────┐
│ 标题栏（主题色深色，标题居中，右侧 最小化/最大化/关闭）        │
├────────────────────────────────────────────────────────────┤
│ [File] Home | Page Layout | References | View   ↙? Options▾ │  ← 标签行（主题色中调）
│   └ (上下文标签：更高、第二主题色、延伸进标题栏)               │
├────────────────────────────────────────────────────────────┤
│ 工具区（白色背景，分组横排，组间竖分隔线）                     │
│  ┌─组─┐ ┌──组──┐ ┌──组──┐ …                                │
│  │按钮│ │组合框│ │流式行│   底部：组名（居中）+ 对话框启动器    │
├────────────────────────────────────────────────────────────┤
│ 状态栏（浅主题色）：左=状态文字  右=视图切换 + 缩放滑块        │
└────────────────────────────────────────────────────────────┘
```

## 2. 配色体系（核心：激活标签"点亮"工具区）

| 区域 | 蓝色主题 | 绿色主题 |
|---|---|---|
| 标题栏 | 深蓝渐变（约 #2A4E93 → #1E3A75） | 深绿渐变（约 #63A83C → #4C8A2C） |
| 标签行 | 中蓝（约 #4A6FBF） | 中绿（约 #7CB84E） |
| 激活标签 | **白/极浅灰背景 + 深色文字**（灯泡效应：功能区被"照亮"） | 同左 |
| File 按钮 | 左端独立块，深色底白字（应用菜单入口） | 深绿底白字 |
| 上下文标签 | **第二主题色**（粉红 #E8B4C8 底/深红文字），位置比普通标签高 4~6px，延伸进标题栏 | 绿色主题下仍为对比色 |
| 工具区 | **纯白** #FFFFFF | 纯白 |
| 悬停态 | 浅蓝圆角渐变填充（约 #CDE3F7→#B5D8F5）+ 1px 蓝边框（#7EB4EA） | 浅绿圆角 + 绿边框 |
| 按下态 | 更深的蓝渐变（#A8CDF0） | 深绿 |
| 正文文字 | 深灰 #1E1E1E；禁用 #A0A0A0 | 同左 |
| 组名 | 灰 #555，底部居中 | 同左 |
| 状态栏 | 白/极浅灰 | **主题绿**（状态栏跟随主题色） |

**关键认知**：Fluent UI 的"激活标签 = 白色工具区"是整个风格的灵魂——标签像灯泡开关，点亮的标签把下方工具区照亮。这与 CAD 软件常见的"全暗色一体化"是两种哲学。

## 3. 分组（Panel）形态

每个组 = 「内容区 + 底部标题行」：

- **内容区**：白底，允许 1~3 行流式排布（不是固定三行槽位）
- **分隔**：组间 1px 竖线（浅灰，上下留边距）
- **组名**：底部居中，灰色小字
- **对话框启动器**：部分组右下角一个 8×8 的小图标（田字/箭头小方块），打开完整对话框——组功能的"更多"入口

观察到的组内容形态：

| 形态 | 例（截图1 Home） | 例（截图2 Page Layout） |
|---|---|---|
| 大按钮 | Paste（32px 图标 + 两行文字） | Themes（复合图标 + ▾ 在下方）、Watermark |
| 横排小按钮（带▾） | Cut ▾ / Copy ▾ 竖排在 Paste 右侧 | Orientation ▾ / Columns ▾ |
| 组合框行 | 字体名框 + 字号框并排（编辑框+▾一体） | — |
| 流式小图标行 | B / I / U / abc / x² / Aa / A / A▼（放不下自动换第二行） | — |
| 数值微调组 | — | Indent: Left [0,3"▴▾] Right[…]；Spacing: Before/After（标签+编辑框+上下微调） |
| 横排带文字按钮（右箭头） | Find ▾ / Replace（禁用灰）/ Select ▾ | — |

**禁用态**：Replace 整个按钮灰色（图标+文字都 #A0A0A0），无交互。

## 4. 按钮三态与几何

- hover：圆角矩形（约 3px）浅主题色填充 + 1px 主题色边框，覆盖按钮矩形
- 按下：更深一档的填充
- 激活（开关类，如居中对齐按钮）：保持浅色高亮填充
- 图标：彩色位图风格（非单色线性），16~32px
- 尺寸：大按钮图标约 32px；小按钮图标 16px；行高约 22px（小按钮）/ 60~86px（组内容区总高）

## 5. 上下文标签（Contextual Tab）

- 选中特定对象（图片）时出现「PICTURE TOOLS → Picture Format」
- 双层文字（组名小字 + 标签名）
- 使用**第二主题色**（与主色对比强烈：蓝主题配粉红）
- 标签矩形更高，顶部延伸进标题栏区域
- 未选中对象时整组消失

## 6. 状态栏

- 背景：浅灰（蓝主题）或主题绿（绿主题跟随）
- 左侧：状态文字序列（Insert | Track Changes: Off | English (U.S.) | Words: 1 | Page 1 of 1）
- 右侧：视图模式切换按钮组（3 个）+ **缩放滑块**（- 100% +）
- 与功能区用细线分隔

## 7. 与本 demo 原实现的差异对照

| 维度 | 原 demo（CAD 暗色风） | Office 风（本次改造目标） |
|---|---|---|
| 工具区背景 | 深灰 #1a1a1a | 白色 #FFFFFF |
| 激活标签 | 底边 2px 强调色 | 白底黑字（点亮工具区） |
| hover | 蓝色半透明矩形 | 浅主题色圆角填充 + 1px 边框 |
| 按钮内容 | 大图标 30px / 小纯图标 | 大/小/横排带字/纯图标/组合框/微调框 |
| 分组内容 | 固定图标列 | 流式多行（1~3 行自适应） |
| File/Options | 无 | 左端 File 块、右端 Options ▾ |
| 上下文标签 | 无 | 第二色高位标签 |
| 对话框启动器 | 无 | 组右下角 |
| 状态栏 | 坐标 + 开关 | 状态文字 + 视图切换 + 缩放滑块（保留坐标与开关） |
| 图标 | 单色线性 SVG 重映射 | （Office 用彩色位图；demo 保留重映射 SVG，颜色映射到浅底深色） |

> 图标适配：Office 风是浅底，图标需用"亮色主题"重映射（icon_bytes::set_light_mode(true)），
> 灰笔画→深灰、蓝强调→Office 蓝，保证白底上可读。
